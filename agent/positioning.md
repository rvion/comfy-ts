# Positioning: where every public word of comfy-ts starts

Every public text opens from this page: a post, a video title and description, a thumbnail, the README's first line, the npm description, a release note's tail. A change of pitch changes this page first.

## The statement, the pitch

**comfy-ts: an efficient way to create, run, maintain and operate your ComfyUI workflows, for humans and agents.**

A free, open source (MIT) TypeScript library. It reads your own ComfyUI and writes an SDK for it, so every node and model autocompletes and a wrong graph is a compile error. The same workflows run from code, one command, a terminal UI, a web panel, an HTTP API or a coding agent, on your GPU, another machine or Comfy Cloud.

## The words

| words | where |
|---|---|
| the pitch, whole | the first line of a post, the README (line 3), the npm description, a video description's first line, a Reddit title as the author's aim (« I made comfy-ts, … ») |
| the pitch cut after « workflows » | a title with a limit (YouTube takes 100 characters) |
| « ComfyUI, typed. » | a thumbnail, the trailer's end card: the whole pitch does not read at that size, and the title beside it carries it |
| `bun add comfy-ts` | the install line under the pitch, everywhere |

## The tone

Plain and factual, one developer speaking: Simplified Technical English, first person where the platform expects a person (Reddit, LinkedIn). No hype words. No superlative and no exaggeration: « an efficient way », never « the most efficient », « the best » or « the fastest ». Every sentence is a fact of the README.

## Who it is for

The readers and gatekeepers of the messages store (`.shipkit/messages/personas.md`, local): leo, ines, sam, marta, kenji; techlead, moderator, comfyorg.

## Reasons to believe

- **typed**: the types come from your own ComfyUI, its nodes and its models, so mistakes show in the editor.
- **anywhere**: workflows run on a local GPU, another machine or Comfy Cloud, and the outputs come back to the code.
- **no code**: the same workflows run from one command, a terminal UI or a browser panel.
- **agents**: a coding agent makes a picture from one sentence with it (the trailer shows it).
- **examples**: ready example workflows for current image, video and audio models ship with it.

## Public against gated

All of it is public: the library, its docs and its trailer are free and open source. Nothing gated.

## Never said

- That it is made by Comfy Org: it is an independent project, and a text that could read so says it is not.
- That it runs the GPU for you or needs no ComfyUI server: it drives your ComfyUI, or Comfy Cloud with your own key, billed to your account.
- A length or a format of the video as the point of a post: a text says what the product does.
- A superlative or a claim over the others (« the most », « the best », « the only »): an efficient way says it without a contest.
