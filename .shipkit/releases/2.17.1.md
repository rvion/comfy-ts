# 2.17.1: A clean exit, linked autogrow inputs
2026-11-03

## CLI

### `comfy-ts serve` on a taken port exits at once
<!-- weight: improvement -->
It prints one line naming the port, the bind and the process that holds it, then exits with code 1. Before, it hung at full CPU and held no port. The serving banner now prints only once the socket listens.

### Stopping `comfy-ts` never leaves its bun process behind
<!-- weight: improvement -->
The node wrapper forwards SIGINT, SIGTERM and SIGHUP to the bun process it starts for `tui`, `serve` and `run`, and that process exits when its parent dies, a SIGKILL included.

## Workflows

### `toWorkflowJson` exports autogrow inputs linked
<!-- weight: improvement -->
An autogrow input (like `TextEncodeQwenImage21.images`) becomes one linked slot per instance, so the exported file opens in the ComfyUI editor with its sources connected and runs the same graph. A literal inside an instance throws. A seed's `control_after_generate` is now written as a real mode, the one the config names or `fixed`, never `false`.

## Web panel

### Confirm and text prompts are drawn in the web panel
<!-- weight: improvement -->
Deletes, renames, the draft overwrite, the ComfyUI restart and the enhancer's new master prompt and new llm buttons now work in an app window built on WKWebView, where `window.prompt` and `window.confirm` return at once.

### The prompt enhancer never turns the model's own lines into yours
<!-- weight: improvement -->
A `// ` or `- ` line the model writes is always dropped, and only the lines you kept come back. Before, with no kept lines in the input, a model could echo your subject as a `- ` line, which the rewrite then applied as a negative.
