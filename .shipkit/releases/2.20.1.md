# 2.20.1: Latent previews on fast runs too
2026-11-19

## Web panel

### The web panel catches the latent preview of a fast run
<!-- weight: improvement -->
The panel already showed the latent preview, but it read a running prompt every 700 ms, so a sampler that ends within a second showed none. It now reads every 150 ms while a prompt runs; an idle panel asks nothing, as before.

## TUI

### No warning of a changed host before the first run
<!-- weight: improvement -->
The TUI header said « changed: +N node types, re-codegen » on a host whose schema was simply not loaded yet. The warning now shows only when a loaded schema really differs from the host.
