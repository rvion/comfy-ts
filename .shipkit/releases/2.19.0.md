# 2.19.0: Claude Code skills in the package
2026-11-17

## Agents

### Claude Code skills ship with the package
<!-- weight: major -->
`comfy-ts skill install` gives Claude Code five slash commands in your project: `/comfy-ts-setup`, `/comfy-ts-workflow`, `/comfy-ts-convert`, `/comfy-ts-run` and `/comfy-ts-guide`. `--user` installs them for every project of yours, and `--dir <skills-dir>` picks the folder. Run it again after an upgrade: a skill file you edited is never overwritten without `--force`, and the command names it.

### The GitHub repo is a Claude Code plugin marketplace
<!-- weight: feature -->
The same skills, for a project that does not install the package: `/plugin marketplace add rvion/comfy-ts`, then `/plugin install comfy-ts@comfy-ts`.

### The agent guide says when code compiles before the first codegen
<!-- weight: improvement -->
With `noUncheckedIndexedAccess` on, run the codegen first.
