# 2.20.0: A host by its id alone
2026-11-19

## Hosts

### A host by its id alone
<!-- weight: feature -->
`comfy.host({ id: 'my-gpu' })` now finds the address that `comfy-ts gen --id my-gpu --host <url>` saved in `.comfy-ts/hosts/my-gpu/host.json`. Committed code names no machine: the address stays in `.comfy-ts/`, which you gitignore. A `url`, or a `host` and `port`, in the call still wins.

### An id with no saved address still imports
<!-- weight: improvement -->
The module loads, logs the reason once, and the first `connect()` or `run()` throws with the path it looked at and the `comfy-ts gen` command that writes it. The file is read again at each use, so a `gen` run under an open TUI or `serve` works without a restart.

## Examples

### The bundled examples name their host by id
<!-- weight: improvement -->
The `examples/rvion` modules call `comfy.host({ id: 'windows-1' })` and carry no address. Run `comfy-ts gen --id windows-1 --host <your ComfyUI>` once to point them at your own server.

## Docs

### The agent guide teaches the id form first
<!-- weight: improvement -->
`comfy.host({ id })` with no address is now the default first step of the guide for coding agents.
